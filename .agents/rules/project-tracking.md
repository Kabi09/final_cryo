# Project Tracking Rule

## Mandatory Rule
Always follow the Project Tracking Instructions:
1. Before making **any change**:
   - Read [project.md](file:///k:/final_cryo/project.md).
   - Understand existing implementation, decisions, and pending work.
   - Check whether the requested change conflicts with anything already documented.
   - Follow the existing approach documented in [project.md](file:///k:/final_cryo/project.md).
2. After making **any change**:
   - Update [project.md](file:///k:/final_cryo/project.md) tracking every feature, UI, component, logic, API, state, routing, bug fix, config, dependency, and structure change.
   - Document any logic changes and technical decisions.
   - Update Current Progress and Change History.
3. Treat [project.md](file:///k:/final_cryo/project.md) as persistent project memory. Never make undocumented changes.
