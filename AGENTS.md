# Agent Guidelines & Project Tracking

## Mandatory Project Tracking Rule
Before making **any change** to this repository:
1. Read [project.md](file:///k:/final_cryo/project.md).
2. Understand existing implementation, technical decisions, and pending tasks.
3. Verify the change doesn't conflict with documented architectural decisions.
4. Implement and verify the change.
5. Update [project.md](file:///k:/final_cryo/project.md) with full details under `Change History`, `Current Progress`, and other relevant sections.

Treat [project.md](file:///k:/final_cryo/project.md) as the persistent single source of truth for the codebase.
